The 6-Stage Assembly Pipeline (`src/v2`)

Every element passes sequentially through modular builders from Stage 0 to Stage 5, ensuring robust and deterministic DOM creation.

0
Create Element

0.createElement.js invokes document.createElement(tagName) with "checkbox" alias mapping.

1
Text Content

1.applyTextContent.js assigns element.textContent if defined.

2
Apply Properties

2.applyProperties.js applies JavaScript object properties directly via Object.assign().

3
Set Attributes

3.applyAttributes.js sets HTML attributes, handles booleans, and maps class.

4
Apply ClassList

4.applyClassList.js tokenizes space-delimited strings or arrays via classList.add(...).

5
Append Children

5.appendChildren.js appends child Node instances or wraps primitives into text nodes.

ES Module Usage

import { buildSpecElement } from "./src/v2/index.js";

const element = buildSpecElement({
  inSpec: {
    tagName: "button",
    classList: "btn btn-primary",
    textContent: "Click Me"
  }
});

document.body.appendChild(element);

Browser Global Usage

<script type="module" src="/src/v2/index.js"></script>
<script type="module">
  const { buildSpecElement } = window.ks["json-to-dom"];

  const el = buildSpecElement({
    inSpec: { tagName: "h3", textContent: "Hello World" }
  });
  document.getElementById("app").appendChild(el);
</script>
