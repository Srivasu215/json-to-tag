Tag Semantic Story & Purpose

The <label> tag provides a usable and accessible caption for interactive form elements. It serves two crucial purposes in web development:

  • Accessibility (a11y): Assistive technologies (such as screen readers) read out the label text when the associated input receives focus.
  • Increased Hit Area: Clicking anywhere on the label text automatically shifts focus to or toggles the linked input control, improving usability on touch devices.

The for Attribute Association

In @keshavsoft/json-to-tag, the for attribute is explicitly validated and permitted in tags.json. Set for to match the target input element's id.

Authoring Specifications in json-to-tag

Pattern A: Explicit Association via for

Pairs with an adjacent <input id="user-email">:

{
  "tagName": "label",
  "classList": "form-label fw-bold",
  "textContent": "Email Address",
  "attributes": {
    "for": "user-email"
  }
}

Pattern B: Nested Children Wrapper (e.g. Checkbox + Text)

Because allowsChildren: true, you can nest an input and text inside:

{
  "tagName": "label",
  "classList": "form-check d-flex align-items-center gap-2",
  "children": [
    {
      "tagName": "checkbox",
      "attributes": { "id": "remember-opt", "checked": true }
    },
    {
      "tagName": "span",
      "textContent": "Keep me logged in"
    }
  ]
}
